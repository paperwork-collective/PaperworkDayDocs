# outline-offset : Outline Offset Property
{: .no_toc }

The `outline-offset` property sets the space between the border of an element and its outline.

## Usage

```css
outline-offset: 4pt;
outline-offset: 0;
outline-offset: -3pt;
```

---

## Values

A length. The default is `0`, so the outline starts at the outside of the border. A negative value draws the outline inside the border.

---

## Notes

- Part of the [outline](css_prop_outline) shorthand. An outline is drawn outside the border and takes up no space.
- Added in Paperwork.Core 9.8.
