# outline-color : Outline Color Property
{: .no_toc }

The `outline-color` property sets the color of the outline.

## Usage

```css
outline-color: red;
outline-color: #2563eb;
outline-color: currentcolor;
```

---

## Values

Any color. `currentcolor` (the default) is the color of the text.

---

## Notes

- Part of the [outline](css_prop_outline) shorthand. An outline is drawn outside the border and takes up no space.
- Added in Paperwork.Core 9.8.
