# outline-style : Outline Style Property
{: .no_toc }

The `outline-style` property sets the style of the outline.

## Usage

```css
outline-style: solid;
outline-style: dashed;
outline-style: dotted;
outline-style: none;
```

---

## Values

`solid`, `dashed`, `dotted`, `none` and `auto` (solid). The other border styles are drawn as solid. The outline is only drawn with a style other than `none`.

---

## Notes

- Part of the [outline](css_prop_outline) shorthand. An outline is drawn outside the border and takes up no space.
- Added in Paperwork.Core 9.8.
