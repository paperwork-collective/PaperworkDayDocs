# word-wrap : Word Wrap Property
{: .no_toc }

The `word-wrap` property is the older name for [overflow-wrap](css_prop_overflow-wrap), and is supported in the same way.

## Usage

```css
word-wrap: normal;
word-wrap: break-word;
```

See [overflow-wrap](css_prop_overflow-wrap) for the values and notes. Added in Paperwork.Core 9.8.
