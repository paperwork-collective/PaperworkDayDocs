# outline-width : Outline Width Property
{: .no_toc }

The `outline-width` property sets the thickness of the outline.

## Usage

```css
outline-width: 2pt;
outline-width: thick;
```

---

## Values

A length, or `thin` (1px), `medium` (3px, the default) or `thick` (5px).

---

## Notes

- Part of the [outline](css_prop_outline) shorthand. An outline is drawn outside the border and takes up no space.
- Added in Paperwork.Core 9.8.
