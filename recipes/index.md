# Recipes
{: .no_toc }

**Recipes are short how-tos for one job each. They are for people who already make documents and want to do one more thing.**

Every recipe is one task on one page, with a working template you can run. The templates are in [Paperwork.Samples](https://github.com/paperwork-collective/Paperwork.Samples) and use fixed dates, so the output is the same every time.

| Recipe | What it does |
|---|---|
| [Password-protect a PDF](/recipes/password-protect.html) | Make a PDF that needs a password to open. |
| [Style alternating columns](/recipes/alternating-columns.html) | Shade or colour every other column of a table. |
| [Build a document index](/recipes/document-index.html) | A contents page with links and the page number of each section. |

If you are new to Paperwork, start with [How it fits together](/overview.html) instead. For a whole document built step by step, see the [Learning guides](/paperwork.core/learning/).
