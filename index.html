  • Give a customer a document from a linkShare a web address that opens the document, filled in for them.
  • Put a document on my own websiteEmbed the Viewer in a page with a few lines of HTML.
  • Make documents from a script or a pipelineRun the command line from a job, a script or a build.
  • Ask your AI assistant to make a documentInstall the skill, then ask in plain English.

Which one do I use?

For people

{% include corners.html %} Paperwork.Design Template Designer You're building or changing a template in HTML and CSS, and deciding who can use it. Designers and frontend developers
{% include corners.html %} Paperwork.Viewer Paperwork.Viewer People fill in forms and download documents, from a link or on your site, on any device. Everyone
{% include corners.html %} Paperwork.Skill AI Skills You want your AI to find a template, fill it in and create the document from your approved version. Anyone with an AI assistant

For code

{% include corners.html %} Paperwork.Core Core Library Your .NET application creates documents from a published template and your own data. Developers
{% include corners.html %} Paperwork.CLI Command Line Documents are created by a script, a scheduled job or a pipeline. Developers and IT
{% include corners.html %} Scryber.Core PDF Engine You want the open-source engine underneath it all, to lay out HTML and CSS as PDF yourself. Developers

Developers provide any data and the integration. Designers build and publish the templates. Your customers and staff fill in simple forms and create documents. Each works in what they know.
