# Create and import
{: .no_toc }

You need to be signed in with a writer account to create a template.

## A new template

Choose **Create** to start a new template. Give it a title, which is required, and an optional description. The title also decides the template's address, so if you already have a template with that title, a number is added to keep it unique.

The Designer opens your new template on a blank page, ready to design.

## Import

Choose **Import** to bring in existing content as a new template. The import is in three steps: **Source**, **Review** and **Details**. There are three kinds of source:

| Source | What it brings in |
|---|---|
| **Template file** | A Paperwork template that was exported from another portal. |
| **Word document** (beta) | A `.docx` or `.dotx` file. Styles, tables, headers and footers come across, and Word merge fields become template fields. |
| **Paste content** | HTML or rich text pasted from any web page, application or word processor. |

You review what was found before you give the new template its title and description.

## Blueprints

A Blueprint is a published example template that you can copy as your own starting point, such as the examples throughout this documentation. Use **Import a Blueprint** to choose a source and a Blueprint, and a copy is created for you to edit.

You can turn your own template into a Blueprint too: see [Publishing and sharing](/paperwork.design/publishing.html).
